# Update learning_order.txt

Select words, then click **Update learning_order.txt…**

MorphMan writes them in `learning_order.txt`, in the order of the table. A manual Study Plan, from one title.

It replaces the file. At the next Recalc (Ctrl+M), the cards that teach these words come first.

To see what's in the file: the [learning_order.txt](../tables/learning-order.md) tab. To write it from several titles at once: the [Study Plan](../readability/study-plan.md).
